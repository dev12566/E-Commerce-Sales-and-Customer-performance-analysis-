# SPO Submission Checklist

Before submitting this self-project for SPO verification:

- [ ] Project is clearly labeled **Self Project** on the master resume.
- [ ] GitHub repository created and accessible.
- [ ] Repository contains the code and analytical artifacts from this package.
- [ ] README explains objective, tools, workflow and findings.
- [ ] Dataset/source is documented.
- [ ] Resume bullets match what is actually present in the repository.
- [ ] No company, internship, faculty mentor, or external affiliation is claimed.
- [ ] Keep a copy of the exact submitted repository and master-resume version.
- [ ] Follow the current SPO portal/email instructions for proof submission.

SPO's current student guidance says self-projects can be verified using code/GitHub links or other proof and that the project should be clearly identified as a self-project.

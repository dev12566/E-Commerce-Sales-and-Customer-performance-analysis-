# E-Commerce Sales & Customer Performance Analysis

**Self Project | Data Analytics Portfolio**

**Tools:** Python, Pandas, SQL, Power BI

## Objective
Analyze e-commerce transactions to understand sales, profitability, customer/product performance, regional trends, discount impact and shipping operations.

## Dataset
Superstore educational dataset.

- Records: 9,994
- Orders: 5,009
- Customers: 793
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02

## Workflow
1. Data validation and cleaning
2. Exploratory analysis in Python/Pandas
3. SQL business analysis
4. KPI and trend analysis
5. Power BI dashboard design
6. Business insights and recommendations

## Power BI Dashboard

The project includes an interactive 5-page Power BI dashboard covering sales, profitability, customers, products, regions, shipping, discounts, and executive insights.

### Dashboard Pages

1. **Executive Overview**
   - Total Sales
   - Total Profit
   - Profit Margin
   - Total Orders
   - Total Customers
   - Average Order Value
   - Sales and Profit trends
   - Sales by Category
   - Sales by Region

2. **Product & Customer Analysis**
   - Product sales performance
   - Product profitability
   - Customer performance
   - Segment analysis
   - Top-performing customers

3. **Regional & Shipping Analysis**
   - Sales by Region
   - Profit by Region
   - Sales by State
   - Profit by State
   - Shipping performance by Ship Mode
   - Average Shipping Days

4. **Discount & Profitability Analysis**
   - Discount analysis
   - Sales and discount relationship
   - Profit by Category
   - Profit Margin by Category
   - Discount band analysis

5. **Executive Insights & Recommendations**
   - Sales and profit trends
   - Category performance
   - Regional profitability
   - Key business insights
   - Management recommendations
